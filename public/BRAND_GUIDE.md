# Veylix Brand Guide

**Tagline:** Scan. Secure. Stay Ahead.  
**Positioning:** A free-first dependency security and maintenance scanner for developers.

## Brand personality
- Clear, calm, and technically credible
- Developer-friendly rather than alarmist
- Minimal and focused on actionable findings
- Honest about data coverage and limitations

## Logo files
- `veylix-logo-horizontal.svg` — primary logo with tagline
- `veylix-icon.svg` — app icon / avatar
- `veylix-wordmark.svg` — wordmark only
- `veylix-icon-monochrome.svg` — single-color icon
- `favicon.svg` — scalable browser favicon

## Color palette
| Token | Hex | Suggested use |
|---|---|---|
| Primary | `#6366F1` | Main actions, links, highlights |
| Accent | `#818CF8` | Secondary emphasis and gradients |
| Light | `#E0E7FF` | Soft selected surfaces |
| Ink | `#0F172A` | Main text and dark UI elements |
| Muted | `#64748B` | Secondary text |
| Surface | `#F8FAFC` | Page background |
| Border | `#E2E8F0` | Dividers and card borders |
| White | `#FFFFFF` | Cards and clear surfaces |

## Typography
Use **Inter** when available. System fallback:
`Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`

- Headings: 600–750
- Body: 400–500
- Labels: 500–600
- Prefer readable sizes and generous line-height.

## UI direction
- Light-first, minimal interface with white cards and pale slate surfaces.
- Use indigo sparingly for primary actions and active states.
- Use severity colors only for security meaning; never rely on color alone.
- Favor clear tables, useful empty states, and concise explanations.
- Avoid excessive gradients, glassmorphism, noisy backgrounds, and fake metrics.

## Voice and messaging
Prefer: “Review affected dependencies”, “No findings detected in the files analyzed”, “Data unavailable from the source”.
Avoid: “100% secure”, “completely safe”, or unverified claims.

Suggested hero:
**Safer Dependencies. Stronger Projects.**
Scan dependencies for known vulnerabilities and maintenance risks, then get clear next steps.

## Accessibility
- Maintain strong text contrast.
- Provide visible focus indicators.
- Use text labels alongside icons.
- Pair severity labels with icons or text, not color alone.
- Respect reduced-motion preferences.

## Usage notes
- Keep clear space around the logo roughly equal to the width of the icon's central stem.
- Do not stretch, skew, recolor arbitrarily, or add heavy shadows to the logo.
- SVG assets are editable vector artwork; verify appearance in your target UI before production use.
